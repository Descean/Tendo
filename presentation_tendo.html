Probleme & Solution

Pourquoi Tendo existe

Les marches publics representent des milliards de FCFA d'opportunites, mais y acceder est un parcours du combattant.

Le probleme

  • Information dispersee : 18+ sites web differents a consulter quotidiennement
  • Documents complexes : PDF de 50+ pages sans resume, en jargon juridique
  • Deadlines ratees : Delais courts, pas de systeme d'alerte
  • Barriere d'entree : PME/TPE n'ont pas les ressources pour veiller
  • Pas de conseil : Aucune aide pour comprendre les exigences de soumission

La solution Tendo

  • Centralisation totale : 18 sources scrapees automatiquement
  • IA qui lit et resume : DeepSeek extrait les infos cles de chaque PDF
  • Alertes WhatsApp instantanees : Notifications avec boutons d'action
  • Accessible a tous : WhatsApp = 95% de penetration au Benin
  • Conseil IA proactif : Analyses du marche et recommandations 2x/semaine

Pipeline de traitement

Du scraping a la notification : chaque etape

Tendo execute une chaine de traitement completement automatisee, de la collecte a la livraison.
1

Scraping automatique (18 sources)

Les 18 scrapers parcourent les sites d'appels d'offres et collectent titre, reference, budget, date limite, URL du PDF, autorite contractante. Le job tourne toutes les 6 heures.

Python BeautifulSoup httpx APScheduler
2

Classification et detection de secteurs

Chaque publication est classifiee par type (AAO, DAO, AMI, PV, Decision ARMP...) et par secteur d'activite (BTP, Sante, IT, Agriculture...). Detection automatique par mots-cles dans 10 categories.

11 types de documents 10 secteurs Regex + NLP
3

Extraction PDF (pypdf + OCR + Vision)

Le texte brut est extrait des PDF en cascade : pypdf 4.3.1 d'abord, puis OCR Tesseract si le PDF est scanne, puis Gemini Vision en dernier recours pour les images.

pypdf Tesseract OCR Gemini Vision
4

Enrichissement IA (DeepSeek Reader)

DeepSeek lit le contenu PDF et extrait 16 champs structures : autorite contractante, budget, garantie de soumission, date/heure de depot, documents requis, conditions de participation, source de financement, etc. 3 passages par jour.

DeepSeek 16 champs structures Fallback Groq/Gemini
5

Segmentation JNMP

Les journaux JNMP (recueils PDF de 10-20+ documents) sont decoupes en appels d'offres individuels. Detection de 25+ types de rubriques avec extraction des metadonnees par regex.

jnmp_analyzer.py 25+ rubriques 2x/jour
6

Filtrage intelligent

Les PV d'attribution, PV d'ouverture et Decisions ARMP sont exclus des notifications et conserves comme base de connaissances pour l'IA conversationnelle. Les AO expires sont supprimes automatiquement chaque nuit.

Knowledge base Auto-cleanup
7

Notification WhatsApp avec boutons

Chaque AO est envoye sur WhatsApp avec un message structure (autorite, objet, reference, type, budget/garantie, deadline) et 3 boutons interactifs : "Voir le dossier", "En savoir plus", "Demander dossier".

Meta Cloud API Messages interactifs Tracking par utilisateur
8

Actions utilisateur (boutons)

Quand l'utilisateur clique un bouton : "Voir le dossier" telecharge le PDF, "En savoir plus" declenche une analyse IA complete, "Demander dossier" envoie un email a l'autorite contractante au nom de l'utilisateur.

PDF download Analyse IA Email SMTP

Architecture technique

Stack production-ready

Infrastructure Docker sur VPS, optimisee pour la performance et la fiabilite.

Architecture globale

Utilisateur (WhatsApp) | v Meta Cloud API ------> Webhook WhatsApp (FastAPI) | +---> Detection d'intent +---> IA Conversationnelle (Groq > Gemini > DeepSeek > Claude) +---> Handlers boutons (voir / savoir / demander) +---> Historique conversation | v PostgreSQL 16 (Docker) ^ | +-------------------------+-------------------------+ | | | Scrapers (18) Scheduler (12 jobs) Admin Dashboard | | | (SPA Alpine.js) v v v Sources web DeepSeek Reader Notifications (ARMP, BAD, (enrichissement) (WhatsApp + boutons) BM, AFD...) | v Email SMTP --------> Autorites contractantes (demande dossier) Inscription (tendo.shiftup.bj) | v FedaPay (Mobile Money MTN/Moov) | v Webhook paiement --> Active abonnement --> Message WhatsApp

Stack Technique

  • Backend : Python 3.11, FastAPI, async
  • ORM : SQLAlchemy 2.0 (asyncpg)
  • Base de donnees : PostgreSQL 16
  • Conteneurisation : Docker Compose
  • Reverse proxy : Nginx + SSL Let's Encrypt
  • Scheduler : APScheduler (in-process)
  • Migrations : Alembic

Integrations externes

  • WhatsApp : Meta Cloud API (1000 conv/mois gratuit)
  • Paiement : FedaPay (MTN/Moov Mobile Money)
  • IA : Groq, Gemini, DeepSeek, Claude
  • PDF : pypdf, Tesseract OCR, Gemini Vision
  • Email : SMTP/IMAP (Gmail)
  • Hebergement : VPS Contabo
